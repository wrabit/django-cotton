# Ecosystem

A growing set of projects built on top of Cotton, from component libraries to editor tooling. Most are third-party and independently maintained. Built something? [Add it](#contribute).

## Component Libraries {#libraries}

Pre-built UI kits and component sets you can drop into a Cotton project.

- **[django-cotton-ui](https://github.com/wrabit/django-cotton-ui)** by Will Abbott. An official Cotton UI kit: themeable interactive components based on Tailwind 4 and Alpine.js 3. [GitHub](https://github.com/wrabit/django-cotton-ui) · [PyPI](https://pypi.org/project/django-cotton-ui/) · [Docs](/ui)
- **[shadcn-django](https://github.com/SarthakJariwala/shadcn-django)** by Sarthak Jariwala. Copy-paste shadcn/ui components for Django, built with Tailwind and Alpine and HTMX-friendly. [GitHub](https://github.com/SarthakJariwala/shadcn-django) · [Website](https://shadcn-django.com)
- **[labb](https://github.com/labbhq/labb)** by labbhq. A large Tailwind and daisyUI 5 component library. [GitHub](https://github.com/labbhq/labb) · [PyPI](https://pypi.org/project/labbui/) · [Website](https://labb.io)
- **[django-basecoat](https://github.com/IgnaceMaes/django-basecoat)** by Ignace Maes. Ready-made Basecoat (shadcn/ui) components for Django, powered by Cotton. [GitHub](https://github.com/IgnaceMaes/django-basecoat) · [PyPI](https://pypi.org/project/django-basecoat/)

## Icons {#icons}

Icon sets exposed as Cotton components.

- **[cotton-icons](https://github.com/wrabit/cotton-icons)** by Will Abbott. An official Cotton icon library exposing the Lucide, Tabler and Heroicons sets as Cotton components. [GitHub](https://github.com/wrabit/cotton-icons) · [PyPI](https://pypi.org/project/cotton-icons/)
- **[cotton-heroicons](https://github.com/snopoke/cotton-heroicons)** by Simon Kelly. The Heroicons set exposed as Cotton components, with outline, solid, mini and micro variants. [GitHub](https://github.com/snopoke/cotton-heroicons) · [PyPI](https://pypi.org/project/cotton-heroicons/)
- **[cotton-iconify](https://github.com/nklsw/cotton-iconify)** by nklsw. A CLI that generates any Iconify icon as a Cotton component. [GitHub](https://github.com/nklsw/cotton-iconify)

## Tooling & CLI {#tooling}

Command-line and development tools for building Cotton components.

- **[cotton-daisy](https://github.com/Qwizi/cotton-daisy)** by Adrian Ciolek. A CLI that scaffolds DaisyUI components for Cotton. Requires DaisyUI and Cotton set up first. [GitHub](https://github.com/Qwizi/cotton-daisy) · [PyPI](https://pypi.org/project/cotton-daisy/)
- **[django-cotton-gallery](https://github.com/velezanthony/django-cotton-gallery)** by Anthony Velez Tapia. A development playground for Cotton components. Turns @prop annotations into live controls, slot IntelliSense, docs and dependency insights, plus a cotton_lint command for CI. [GitHub](https://github.com/velezanthony/django-cotton-gallery) · [PyPI](https://pypi.org/project/django-cotton-gallery/) · [Docs](https://velezanthony.github.io/django-cotton-gallery/)

## Editor Support {#editors}

Editor extensions that understand Cotton's component tags.

- **[Django Cotton (VS Code)](https://marketplace.visualstudio.com/items?itemName=twentyforty.django-cotton)** by twentyforty. Autocomplete, hover docs and go-to-definition for components, props and slots, plus Find All References, unused-component detection, and diagnostics for missing components and slot-name typos. [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=twentyforty.django-cotton) · [Open VSX](https://open-vsx.org/extension/twentyforty/django-cotton)
- **[Django Cotton Highlighting (VS Code)](https://marketplace.visualstudio.com/items?itemName=DavidBloomer.django-cotton-highlighting)** by David Bloomer. Syntax highlighting for .cotton.html files, plus autocomplete, hover docs, go-to-definition and unknown-component diagnostics. [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=DavidBloomer.django-cotton-highlighting)
